# 민재 제트기 게임

테마별 스테이지, 월드 2, 제트기·부품 상자, 60초 랭크 도전이 있는 브라우저 슈팅 게임입니다.

## 실행

Node.js 24 이상에서 다음 명령을 실행한 뒤 http://127.0.0.1:8000 을 엽니다.

```sh
PORT=8000 node online/server.mjs
```

별도 패키지 설치는 필요하지 않습니다. 랭킹은 `online/data/leaderboard.sqlite`에 저장되며 이 폴더는 Git에서 제외됩니다. 기존 서버를 업데이트할 때 이 파일을 보존하세요.

## 최신 변경

- 60초 동안 무적 보스에게 준 피해로 랭크 결정, 체력이 소진되면 조기 종료
- 주포 기본 피해 3, 제트기 공격 보너스와 부품 탄환 피해 추가
- 랭크전에서 11종 잡몹 무작위 등장 및 자동 코인 획득, 월드 2 코인 2배
- 루키부터 코스믹까지 12종 배지
- 랭크전 적 탄환 속도 20% 감소, 공격 빈도 완화, 보스 공격 전 3초 대기
- 플레이어별 누적 포인트 랭킹 및 최고 피해·등급 초기화
- 전체화면과 상향 배치한 강화 버튼

## 온라인 랭킹 운영

GitHub Pages는 HTML 게임 화면을 제공할 수 있지만 이 Node.js 랭킹 서버는 실행하지 않습니다. 온라인 랭킹은 위 서버를 실행하는 호스팅에서 게임과 `/api/`를 같은 주소로 제공해야 동작합니다. 필요한 경우 `HOST`, `PORT`, `LEADERBOARD_DB` 환경변수로 서버 설정을 지정할 수 있습니다.

현재 플레이어 구분은 브라우저에 저장된 식별자를 사용하며, 점수 검증은 기본적인 범위·시간 검사입니다. 계정 인증 및 서버에서 실제 플레이를 검증하는 기능은 포함되어 있지 않습니다. 다른 브라우저에서는 별도 플레이어로 취급됩니다.
